# Graph Algorithms

| File | Description |
|------|-------------|
| [bfs.py](bfs.py) | Breadth-first search using deque |
| [bfs_2.py](bfs_2.py) | BFS shortest path finder |
| [dfs.py](dfs.py) | Depth-first search — recursive and iterative |
| [dijkstra.py](dijkstra.py) | Dijkstra shortest path using min-heap |

## Key concepts
- **BFS** — explores neighbors level by level; good for shortest path in unweighted graphs
- **DFS** — goes deep before backtracking; good for cycle detection, topological sort
- **Dijkstra** — shortest path in weighted graphs with non-negative edges
