# Testing

Python unit testing examples using `unittest`.

| File | Description |
|------|-------------|
| [test_1.py](test_1.py) | Basic unit test examples |
| [test.py](test.py) | Additional test cases |
| [test_lib.py](test_lib.py) | Testing a library |
| [main_code.py](main_code.py) | Code being tested |

## Running tests
```bash
python -m pytest testing.py/
# or
python -m unittest discover testing.py/
```
